Passphrase-protected dashboard of paper-trading results (no real money, not investment advice). GitHub Actions in the private research repo encrypts the allow-listed P&L, trades, holdings, EOD AI commentary and strategy write-ups into `data/dashboard.enc.json` (PBKDF2-SHA256 600k + AES-256-GCM); the page decrypts it locally in your browser. No plaintext data is published.
